> # V2Ray Config Hub | Only Working WebSocket Nodes
> ## Auto-updated hourly | 500+ configs tested | Pakistan, Singapore, UAE, India & more

[![GitHub Actions](https://github.com/zabikh/zabikh/actions/workflows/update-configs.yml/badge.svg)](https://github.com/zabikh/zabikh/actions/workflows/update-configs.yml)

## 🔥 Features
- **Real WebSocket validation** – no fake alive configs
- **Ping under 800ms** – only fast servers
- **Accurate countries** – Pakistan, India, UAE, Singapore, Germany, Netherlands, Japan, US, Canada, UK, France, Australia, Brazil, Russia
- **Auto-updates every hour** via GitHub Actions
- **Hacker theme** – matrix background, glitch effects

## 📡 Live Dashboard
👉 [https://zabikh.vercel.app](https://zabikh.vercel.app)

## 🛠️ How it works
1. GitHub Actions fetches from 15+ public sources every hour.
2. Tests TCP ping + WebSocket endpoint for each config.
3. Saves only alive configs with low ping to `configs.json`.
4. Vercel serves static JSON – instant load, no timeouts.
